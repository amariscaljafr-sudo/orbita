# Órbita

Espacio personal para organizar el día a día: calendario, tareas, avisos, notas y secciones a medida (armario, entrenos, películas, estudios…).

- Web instalable: ábrela en Safari y usa **Compartir → Añadir a pantalla de inicio**.
- Funciona sin conexión.
- Los datos se guardan solo en el dispositivo (localStorage). Para pasarlos a otro dispositivo: **Perfil → Exportar copia / Importar copia**.
